Tensor AAA
===================================
Joint pole-expansion of tensor-valued functions with a shared set of poles, as introduced in
'Pole-Expansion of the T-Matrix Based on a Matrix-Valued AAA-Algorithm' (https://doi.org/10.1021/acsphotonics.6c00436).
See :doc:`../examples/chiral_sphere` for an example.
